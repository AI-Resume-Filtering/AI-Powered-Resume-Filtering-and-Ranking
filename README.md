# 🎯 AI Resume Ranking System

> Automate your hiring process with intelligent resume screening powered by AI


---

## 💡 What is This?

An AI-powered system that **automatically screens and ranks resumes** for recruiters. Upload a job description and resumes, and get an intelligent, ranked list of candidates in seconds.

**No more manual screening. No more missed talent. Just smart hiring.**

---

## ✨ Why This Matters

Recruiters receive **hundreds of resumes** per job posting. Manually reviewing each one takes hours and risks missing great candidates.

**Our Solution:**
- ⚡ **Instant Screening** - Process 100+ resumes in seconds
- 🎯 **Smart Matching** - AI understands skills beyond keywords
- 📊 **Clear Rankings** - Know exactly who to interview first
- 🔍 **Explainable Results** - See why each candidate scored as they did

---

## 🚀 How It Works

```
📄 Upload Job Description → 📂 Upload Resumes → 🤖 AI Processing → 📊 Ranked Results
```

1. **Upload** your job description
2. **Add** candidate resumes (PDF/DOCX)
3. **Get** ranked candidates with match scores
4. **Review** top matches and interview faster

## 🎯 Key Features

| Feature | Description |

| 🧠 **Smart Parsing** | Extracts skills, experience, education from any resume format |

## 📂 Project Structure


## 🎬 Quick Start

```bash
# Clone the project
git clone https://github.com/yourusername/ai-resume-ranking.git

# Install dependencies
pip install -r requirements.txt

# Run the system
python main.py --jd JD_001 --resumes ./resumes_folder/
```

**That's it!** Get ranked results instantly.
